# Руководство по созданию модулей 🛠

Юзербот использует библиотеку **Pyrogram** и поддерживает динамическую подгрузку модулей. Любой `.py` файл, помещенный в папку `modules/`, автоматически становится плагином и загружается при старте бота.

## 1. Базовая структура модуля

Каждый модуль — это отдельный Python-скрипт, в котором регистрируются обработчики команд (хендлеры). 
Чтобы ваш модуль корректно отображался в общем меню `.help`, добавьте в самое начало файла две специальные переменные:

- `__MODULE__` — Название вашего модуля (желательно с эмодзи).
- `__HELP__` — Описание команд (используйте HTML-тег `<code>` для выделения самих команд).

## 2. Шаблон для быстрого старта

Вот готовый пример простейшего модуля. Вы можете скопировать его, сохранить как `hello.py` и загрузить в бота.

```python
__MODULE__ = "Приветствие 👋"
__HELP__ = "<code>.hello</code> — Написать приветствие в чат"

from pyrogram import Client, filters
from pyrogram.types import Message

# Обязательно импортируем ONLY_ME, чтобы чужие люди не могли управлять вашим ботом!
from utils import ONLY_ME 

@Client.on_message(filters.command("hello", prefixes=".") & ONLY_ME)
async def hello_handler(client: Client, msg: Message):
    # msg.edit заменяет ваше исходное сообщение ".hello" на новый текст
    await msg.edit("Привет! Я модульный юзербот! 🚀")
```

## 3. Важные правила разработки

1. **Безопасность (`ONLY_ME`):** Всегда добавляйте `& ONLY_ME` в декоратор `filters.command(...)`. Если этого не сделать, любой участник группы сможет выполнить вашу команду от вашего имени!
2. **Префиксы:** По умолчанию во всём юзерботе используется префикс `.` (точка). Рекомендуется придерживаться этого стандарта.
3. **Редактирование сообщений:** Юзербот — это вы. Когда вы пишете `.команда`, вы отправляете реальное сообщение. Поэтому почти во всех хендлерах используется `await msg.edit("новый текст")`, чтобы красиво и бесшовно заменить саму команду на итоговый результат.
4. **Асинхронность (`async / await`):** Не используйте блокирующие вызовы (например, `time.sleep()`). Для задержек всегда используйте `await asyncio.sleep()`.

## 4. Использование общих утилит (`utils.py`)

В корне проекта есть файл `utils.py`. В нём хранятся полезные функции и переменные.
Вы можете смело импортировать их в свой модуль, чтобы не писать код с нуля:

```python
import asyncio
from utils import loading_effect, usa_emoji, link_emoji

@Client.on_message(filters.command("load", prefixes=".") & ONLY_ME)
async def load_handler(client: Client, msg: Message):
    # Красивая анимация загрузки из 3 кадров
    await loading_effect(msg, "Обработка данных", "⏳")
    await asyncio.sleep(1)
    await msg.edit("Данные успешно загружены! ✅")
```

## 5. Как загрузить готовый модуль в бота?

Вам **не обязательно** заходить на сервер через SSH, чтобы протестировать или обновить код!
1. Напишите код на компьютере или телефоне и сохраните его в файл (например, `test.py`).
2. Отправьте этот файл как документ в **"Избранное"** (Saved Messages) в Telegram.
3. Ответьте на это сообщение (Reply) командой `.`dlmod``.
4. Бот сам скачает файл в папку `modules`, мгновенно перезапустится, и модуль тут же появится в `.help`!
